Konfigurasi Firebase dulu, ya

File ini butuh Firebase Realtime Database sebagai "server" real-time, karena GitHub Pages cuma hosting statis (tidak bisa jalanin server sendiri). Ikuti langkah berikut sekali saja:

  1. Buat project Firebase — buka console.firebase.google.com, klik "Add project", ikuti wizard-nya (boleh matikan Google Analytics).
  2. Aktifkan Realtime Database — di sidebar pilih Build → Realtime Database → Create Database. Pilih lokasi server terdekat, lalu mulai dalam test mode dulu (nanti kita ganti dengan rules yang lebih aman di langkah 5).
  3. Aktifkan Anonymous Authentication — di sidebar pilih Build → Authentication → Get started, lalu di tab "Sign-in method" aktifkan provider Anonymous. Ini dipakai supaya tiap pemain punya ID unik tanpa perlu daftar/login.
  4. Ambil Firebase config — di halaman utama project, klik ikon web </> untuk "Add app" (kalau belum ada), kasih nama bebas, lalu Firebase akan menampilkan objek firebaseConfig. Salin isinya, lalu ganti seluruh objek firebaseConfig di dekat baris paling atas <script type="module"> pada file index.html ini dengan hasil salinan tadi. Simpan filenya.
  5. Pasang Security Rules — kembali ke Realtime Database → Rules, tempel aturan berikut (mencegah pemain memalsukan progres pemain lain / mundur ke belakang), lalu klik Publish: 
    memuat contoh rules…
  6. Upload ke GitHub Pages — buat repo baru, upload file index.html ini ke root repo, lalu aktifkan di Settings → Pages → Deploy from branch. Setelah beberapa menit, game bisa dimainkan lewat URL https://namamu.github.io/namarepo/.

Setelah firebaseConfig diganti dan file disimpan ulang, halaman ini otomatis hilang dan game siap dimainkan.
